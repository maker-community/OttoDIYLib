## 电源配置

### 推荐电源方案
```
外部电源 (6V-7.4V)
    │
    ├─── 舵机供电 (直接供电)
    └─── Arduino VIN (稳压后给Arduino供电)

注意事项:
- 舵机需要足够的电流 (每个舵机约500mA)
- 6个舵机至少需要3A电流
- 使用独立电源给舵机供电，避免Arduino供电不足
```

### 简化电源方案 (测试用)
```
USB电源 (5V)
    │
    ├─── Arduino 5V引脚
    └─── 舵机VCC (仅适合轻负载测试)

警告:
- USB供电电流有限 (通常500mA-1A)
- 多个舵机同时工作可能导致电压不稳
- 仅适合单独测试舵机或轻负载演示
```

  ↓ (PWM信号)

```

  ↓ (PWM信号)

```

## 串口协议时序

### 命令发送时序
```
发送端                     Arduino Nano
  │                           │
  ├─ "WALK:2,1000,1,30\n" ──► │
  │                           ├─ 解析命令
  │                           ├─ 执行动作
  │                           └─ 发送响应
  │ ◄── "OK:WALK" ────────────┤
  │                           │
  └─ 等待动作完成              └─ 继续监听命令
```

### 错误处理时序
```
发送端                     Arduino Nano
  │                           │
  ├─ "INVALID_CMD\n" ────────► │
  │                           ├─ 命令无法识别
  │                           └─ 发送错误响应
  │ ◄── "ERROR:Unknown command" ┤
  │                           │
  └─ 处理错误信息              └─ 继续监听命令
```

## 故障排除连接

### 常见连接问题

1. **串口不通信**
   - 检查TX/RX是否交叉连接
   - 确认波特率设置 (115200)
   - 检查GND连接

2. **舵机不动作**
   - 检查舵机供电
   - 确认信号线连接
   - 测试单个舵机

3. **动作不协调**
   - 检查舵机安装方向
   - 调整微调参数
   - 确认引脚定义

### 测试连接步骤

1. **基础连接测试**
   ```
   发送: INIT
   期望: OK:INIT
   ```

2. **舵机测试**
   ```
   发送: SERVO_MOVE:0,90
   期望: OK:SERVO_MOVE + 舵机转动到90度
   ```

3. **动作测试**
   ```
   发送: HOME:1
   期望: OK:HOME + 机器人回到初始位置
   ```

4. **状态查询**
   ```
   发送: GET_STATUS  
   期望: STATUS:resting=true,has_hands=true
   ```

## 扩展连接

### 添加传感器
```
Arduino Nano
    │
    ├── A0 ──── 距离传感器
    ├── A1 ──── 光线传感器
    ├── A2 ──── 按钮
    └── A3 ──── 电压监测
```

### 添加显示
```
Arduino Nano
    │
    ├── A4 (SDA) ──┐
    ├── A5 (SCL) ──┤─── I2C OLED显示屏
    │              │
    └─ 显示状态信息 ┘
```

这种模块化设计使得系统既可以独立工作，也可以集成到更大的系统中，提供了很好的灵活性和扩展性。
