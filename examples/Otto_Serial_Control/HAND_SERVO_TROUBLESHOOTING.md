# 手臂舵机连接和故障排除指南

## 硬件连接检查清单

### 舵机连接
确保所有舵机正确连接到指定引脚：

```
基础舵机 (Otto库管理):
- 左腿舵机  -> Arduino D3  (PWM)
- 右腿舵机  -> Arduino D5  (PWM)
- 左脚舵机  -> Arduino D6  (PWM)
- 右脚舵机  -> Arduino D9  (PWM)

手臂舵机 (扩展功能):
- 左手舵机  -> Arduino D10 (PWM)
- 右手舵机  -> Arduino D11 (PWM)

其他组件:
- 蜂鸣器    -> Arduino D13
- 状态LED   -> Arduino D13 (内置LED)
```

### 电源连接
**重要**: 舵机需要独立的5V电源供电！

```
Arduino供电:
- USB线 或 VIN引脚 (7-12V)

舵机供电:
- 独立5V电源 (推荐3-5A电流)
- 所有舵机的红线连接到5V电源正极
- 所有舵机的黑线连接到5V电源负极
- 5V电源负极必须与Arduino GND相连 (共地)
- 舵机信号线连接到对应的Arduino数字引脚
```

## 常见问题排除

### 1. 手臂舵机不动作

**可能原因和解决方案:**

#### A. 电源问题
- **检查**: 舵机是否有独立5V电源
- **解决**: 使用3-5A的5V电源适配器，确保电流充足
- **测试**: 用万用表测量舵机红线电压应为4.8-5.2V

#### B. 连接问题
- **检查**: 舵机信号线是否连接到正确引脚
- **解决**: 
  ```
  左手舵机信号线 -> Arduino D10
  右手舵机信号线 -> Arduino D11
  ```
- **测试**: 用示波器或万用表检查引脚是否有PWM信号输出

#### C. 代码问题
- **检查**: 是否正确包含Servo库
- **解决**: 确保代码中有 `#include <Servo.h>`
- **测试**: 上传简单测试代码验证舵机控制

#### D. 舵机故障
- **检查**: 舵机本身是否正常
- **解决**: 用简单的Arduino舵机测试代码单独测试每个舵机
- **测试代码**:
  ```cpp
  #include <Servo.h>
  Servo testServo;
  
  void setup() {
    testServo.attach(10);  // 测试D10引脚的舵机
  }
  
  void loop() {
    testServo.write(0);
    delay(1000);
    testServo.write(90);
    delay(1000);
    testServo.write(180);
    delay(1000);
  }
  ```

### 2. 舵机抖动或异常

**可能原因和解决方案:**

#### A. 电源不稳定
- **检查**: 电源电压是否稳定
- **解决**: 使用大容量电容 (1000μF以上) 在电源两端滤波
- **建议**: 使用开关电源而非线性电源

#### B. 信号干扰
- **检查**: 信号线是否与电源线并行走线
- **解决**: 信号线与电源线分开走线，使用屏蔽线
- **改进**: 在信号线上串联100Ω电阻减少干扰

#### C. 负载过大
- **检查**: 舵机是否承受过大机械负载
- **解决**: 减轻负载或更换更大扭矩的舵机
- **预防**: 确保舵机轴转动顺畅，无卡死

### 3. 串口通信问题

**可能原因和解决方案:**

#### A. 波特率不匹配
- **检查**: Arduino代码和测试程序波特率是否一致
- **解决**: 确保都使用115200波特率

#### B. COM端口错误
- **检查**: 是否选择了正确的COM端口
- **解决**: 在设备管理器中查看Arduino对应的COM端口号

#### C. 串口占用
- **检查**: 是否有其他程序占用串口
- **解决**: 关闭Arduino IDE的串口监视器等工具

## 测试步骤

## 性能优化建议

### 1. 电源优化
- 使用足够容量的电源 (推荐5A以上)
- 在电源两端加大容量滤波电容
- 考虑使用多路稳压器分别供电

### 2. 代码优化
- 避免同时快速移动多个舵机
- 使用适当的延时确保动作完成
- 实现平滑的舵机运动算法

### 3. 机械优化
- 确保舵机轴承转动顺畅
- 使用质量好的舵机臂和连接件
- 定期检查和维护机械连接
