## 舵机连接详图

每个舵机有3根线：
- **红线**: +5V (连接到舵机电源正极)
- **棕线/黑线**: GND (连接到公共地)
- **橙线/白线**: 信号线 (连接到Arduino数字引脚)

```
舵机布局 (从后面看Otto):

      左手(D10)    右手(D11)
           │          │
           │          │
      左腿(D3)      右腿(D5)
           │          │
           │          │
      左脚(D6)      右脚(D9)
```

## 连接步骤

### 1. 准备材料
- Arduino Nano
- 6个SG90舵机
- 杜邦线若干
- 5V电源模块 (3-5A)
- 面包板或万能板

### 2. 连接舵机信号线
按照引脚分配连接每个舵机的信号线到对应的Arduino数字引脚

### 3. 连接电源
- 所有舵机红线连接到5V电源正极
- 所有舵机棕/黑线连接到公共地
- Arduino GND连接到公共地

### 4. 连接串口
- ESP32 TX → Arduino D0 (RX)
- ESP32 RX → Arduino D1 (TX)
- ESP32 GND → Arduino GND

### 5. 测试连接
- 上传程序到Arduino
- 打开串口监视器 (115200波特率)
- 发送 "INIT" 命令测试

## 故障排除

### 舵机不动
1. 检查电源连接
2. 确认5V电源电流足够
3. 检查信号线连接

### 串口无响应
1. 确认波特率设置为115200
2. 检查RX/TX连接是否正确
3. 确认ESP32和Arduino共地

### 动作不协调
1. 使用SET_TRIMS命令微调舵机
2. 检查舵机机械安装
3. 确认舵机转向正确

## 安全注意事项

⚠️ **警告**:
- 确保舵机电源电压在4.8-6V之间
- 不要让Arduino 5V引脚直接给6个舵机供电
- 始终保持电源共地
- 避免短路，检查连接后再通电
