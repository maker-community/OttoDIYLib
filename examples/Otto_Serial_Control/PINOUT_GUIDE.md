## 连接注意事项

### 1. 舵机电源
- **重要**: 舵机需要外部5V电源，Arduino的5V输出电流有限（最大500mA）
- 6个舵机同时工作可能需要3-5A电流
- 建议使用独立的5V电源模块为舵机供电

### 2. 共地连接
- 确保Arduino和舵机电源共地（GND连接）
- 这是避免信号干扰的关键

### 3. PWM频率
- Arduino Nano的PWM频率约490Hz
- 适合大多数SG90等微型舵机
- 如果舵机抖动，可能需要调整PWM频率

### 4. 引脚冲突避免
- **D0, D1**: 用于串口通信，不要占用
- **D13**: 内置LED，可以用作状态指示和蜂鸣器
- **A4, A5**: I2C接口，如需要可用于传感器

## 传统Otto引脚分配（兼容性）

如果你的硬件已经按照传统Otto引脚连接，也可以使用：

```cpp
#define LEFT_LEG_PIN    2   // 左腿舵机
#define RIGHT_LEG_PIN   3   // 右腿舵机  
#define LEFT_FOOT_PIN   4   // 左脚舵机
#define RIGHT_FOOT_PIN  5   // 右脚舵机
#define LEFT_HAND_PIN   6   // 左手舵机 (可选)
#define RIGHT_HAND_PIN  7   // 右手舵机 (可选)
```

虽然D2, D4, D7不是PWM引脚，但现代的Servo库可以在任何数字引脚上生成伺服信号（通过软件PWM）。

## 串口通信

### 硬件串口（推荐）
- **RX (D0)**: 接收ESP32的TX
- **TX (D1)**: 发送到ESP32的RX
- **波特率**: 115200
- **用途**: 接收控制命令，发送状态反馈

### 软件串口（可选）
如果需要保留硬件串口用于调试：
```cpp
#include <SoftwareSerial.h>
SoftwareSerial esp32Serial(8, 9); // RX, TX
```

## 调试建议

1. **串口监视器**: 使用Arduino IDE的串口监视器查看状态信息
2. **状态LED**: D13上的LED会显示心跳信号
3. **分步测试**: 先测试单个舵机，再测试组合动作
4. **电压检查**: 确保舵机电源电压稳定在4.8-6V之间

## 常见问题排查

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 舵机不动 | 电源不足 | 检查舵机电源和连接 |
| 舵机抖动 | 信号干扰 | 检查共地连接 |
| 串口无响应 | 波特率不匹配 | 确认串口设置为115200 |
| 动作不协调 | 舵机微调问题 | 使用SET_TRIMS命令调整 |
